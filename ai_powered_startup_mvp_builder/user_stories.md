# User Stories - Team Request & Live Chat Hub

## User Story 1
As a user, I want to submit a new request through a clean text form so that my team can capture actionable tasks or feedback quickly.

## User Story 2
As a user, I want every submitted request to be saved automatically with a timestamp so that I know when each item was created.

## User Story 3
As a returning user, I want previously submitted requests to persist after I refresh the page so that no team submissions are lost between sessions.

## User Story 4
As a user, I want to switch between the Requests view and the Chat view using a tab navigation bar so that I can move between structured tasks and live discussion without reloading the page.

## User Story 5
As a user, I want the currently active tab to be visually highlighted so that I always know which section of the application I am viewing.

## User Story 6
As a chat participant, I want to be prompted to enter a username before joining the conversation so that all messages in the thread are clearly attributed.

## User Story 7
As a chat participant, I want to send and view real-time messages with sender usernames and timestamps so that I can coordinate with teammates smoothly.

## User Story 8
As a user, I want to see a confirmation toast when my request or chat message is submitted so that I know the action succeeded.

## User Story 9
As a user, I want to see a clear inline error message if I try to submit an empty input or if a storage error occurs so that I can correct my input immediately.

## User Story 10
As a mobile or desktop user, I want the layout, forms, and chat window to adapt responsively to my screen size so that I can use the app comfortably on any device.
