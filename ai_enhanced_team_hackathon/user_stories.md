User Stories

Core MVP User Stories

Goal & Availability Input

As a self-directed learner,

I want to input my target skill, current proficiency level (Beginner, Intermediate, Advanced), and weekly available study hours,

So that the system can tailor a realistic learning schedule to my personal constraints.

AI Roadmap Generation

As a learner starting a new topic,

I want the AI to generate a structured, week-by-week syllabus with clear milestones and daily topics,

So that I know exactly what to study each day without getting overwhelmed by resource overload.

View Curated Topic Summaries & Resources

As a student working through a daily module,

I want to view key concepts and recommended search terms/resources for that specific topic,

So that I can immediately start learning without wasting time searching for where to begin.

Daily Micro-Quiz Generation

As a learner finishing a daily study module,

I want to generate a 3-to-5 question multiple-choice quiz tailored to that day's specific topic,

So that I can actively test my comprehension and reinforce my memory.

Immediate Quiz Feedback & Explanations

As a user taking a micro-quiz,

I want to receive instant grading along with brief explanations for why an answer is correct or incorrect,

So that I can immediately clear up any misunderstandings before moving on.

Interactive Progress Tracking

As a learner following a multi-week plan,

I want to mark individual daily modules and weekly milestones as "Completed,"

So that I can visually track my overall progress percentage and stay motivated.

Dynamic Timeline Adjustment

As a busy student who occasionally falls behind schedule,

I want to recalculate or shift my remaining uncompleted modules forward with one click,

So that my study plan remains realistic and achievable without having to start over.

Save & Resume Learning Roadmaps

As a returning user,

I want my generated roadmaps, quiz scores, and completion statuses to be saved automatically,

So that I can pick up right where I left off across different sessions.

Regenerate Specific Module (Stretch)

As a learner who already knows a specific sub-topic,

I want to ask the AI to regenerate or skip a single module and replace it with a more advanced concept,

So that I don't waste time reviewing material I have already mastered.
