Data Model

Overview

The application uses a relational data structure to persist user profiles, generated learning roadmaps, individual study modules, and micro-quiz assessments.

Entities & Schema Definitions

1. Users

Stores basic learner identification and authentication metadata.

id (UUID / INTEGER, Primary Key): Unique identifier for the user.

email (VARCHAR(255), Unique, Not Null): User's email address for login/session persistence.

name (VARCHAR(100), Not Null): Display name of the learner.

created_at (TIMESTAMP, Default: CURRENT_TIMESTAMP): Account creation timestamp.

2. Roadmaps

Represents a high-level learning plan generated by the AI for a specific goal.

id (UUID / INTEGER, Primary Key): Unique identifier for the roadmap.

user_id (UUID / INTEGER, Foreign Key -> Users.id): Owner of the roadmap.

target_skill (VARCHAR(255), Not Null): The topic or skill being learned (e.g., "Full-Stack React & Node.js").

proficiency_level (ENUM('Beginner', 'Intermediate', 'Advanced'), Not Null): Starting knowledge level.

hours_per_week (INTEGER, Not Null): Time commitment constraint used by the LLM to size modules.

status (ENUM('Active', 'Completed', 'Archived'), Default: 'Active'): Current state of the learning plan.

created_at (TIMESTAMP, Default: CURRENT_TIMESTAMP): Timestamp when the roadmap was generated.

3. Study_Modules

Represents individual daily or topical lessons inside a roadmap.

id (UUID / INTEGER, Primary Key): Unique identifier for the study module.

roadmap_id (UUID / INTEGER, Foreign Key -> Roadmaps.id): Parent roadmap reference.

week_number (INTEGER, Not Null): Week sequence index (e.g., 1, 2, 3).

day_number (INTEGER, Not Null): Day sequence index within the week (e.g., 1–7).

title (VARCHAR(255), Not Null): Concise title of the daily lesson.

summary_content (TEXT, Not Null): AI-generated overview, key concepts, and suggested study prompts/resources.

is_completed (BOOLEAN, Default: FALSE): Tracks whether the user has finished this module.

scheduled_date (DATE, Nullable): Target date for completion (dynamically updated if timeline shifts).

4. Quiz_Attempts

Stores AI-generated micro-quizzes and user assessment outcomes for a given module.

id (UUID / INTEGER, Primary Key): Unique identifier for the quiz attempt.

module_id (UUID / INTEGER, Foreign Key -> Study_Modules.id): Associated study module.

questions_json (JSONB / TEXT, Not Null): Structured JSON array containing questions, multiple-choice options, correct answer index, and explanations.

user_score (INTEGER, Nullable): Number of questions answered correctly.

total_questions (INTEGER, Not Null): Total number of questions in the generated quiz (typically 3–5).

completed_at (TIMESTAMP, Nullable): Timestamp when the user submitted the quiz.
